= Novedades de SnapCenter software 6.2.1
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La versión 6.2.1 del software SnapCenter no incluye nuevas funciones ni mejoras. Incluye solo correcciones de errores conocidos y actualizaciones de las versiones cualificadas para el servidor SnapCenter y los plug-ins. Consulta el link:https://library.netapp.com/ecm/ecm_download_file/ECMLP3359467["SnapCenter 6.2.1 Notas de la versión"^] para más detalles.
