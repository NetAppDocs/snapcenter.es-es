= Configura credenciales para el clúster PostgreSQL
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Debes configurar las credenciales de usuario del clúster PostgreSQL para realizar operaciones de protección de datos.

.Antes de empezar
* Si el clúster PostgreSQL no tiene credenciales válidas configuradas, aparecerá un icono de candado rojo solo para los recursos autodetectados. Si durante una operación de descubrimiento posterior, se descubre que las credenciales configuradas son incorrectas o no proporcionan acceso al propio clúster, volverá a aparecer el icono de candado rojo.
* Debes configurar credenciales de clúster PostgreSQL válidas para poder proteger el recurso o añadirlo a un grupo de recursos para realizar operaciones de protección de datos.
* El usuario PostgreSQL configurado en las credenciales debe tener privilegios suficientes para acceder al clúster y realizar operaciones de copia de seguridad y restauración. Como mínimo, el usuario debe tener el rol *SUPERUSER* o privilegios equivalentes (como *pg_read_all_data*, *pg_write_all_data* y permisos de *replication*).
* SnapCenter utiliza las credenciales configuradas para conectarse a la instancia de PostgreSQL mediante el cliente *psql* o *libpq*. Asegúrate de que las herramientas de cliente de PostgreSQL estén instaladas en el host del complemento.



NOTE: Antes de configurar el clúster, primero debes añadir las credenciales de PostgreSQL a SnapCenter.

.Pasos
. En el panel de navegación izquierdo, selecciona *Resources* y luego selecciona SnapCenter Plug-in for PostgreSQL cluster de la lista.
. En la página Resources, seleccione el tipo de recurso en la lista *View*.
. (Opcional) Selecciona image:../media/filter_icon.gif["icono de filtro"] y selecciona el nombre de host.
+
A continuación, puedes seleccionar image:../media/filter_icon.gif["icono de filtro"] para cerrar el panel de filtrado.

. Selecciona el clúster y luego selecciona *Configurar credenciales*.
. Selecciona la credencial que se ha configurado en SnapCenter para el usuario del clúster PostgreSQL. La credencial debe incluir un nombre de usuario y una contraseña válidos con privilegios suficientes para realizar operaciones de protección de datos.
. Seleccione *OK*.


Puedes modificar la configuración del clúster desde la página Topología.
